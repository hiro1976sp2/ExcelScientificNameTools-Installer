# 生物種リスト作成支援ツール

Excelで生物種リスト等を整形するためのVSTOアドインです。



## 主な機能

- 学名のイタリック整形
- 学名表記の空白調整
- 同一分類群の省略
- 表の罫線整形
- その他



## 動作環境

- Windows 10 / 11
- Microsoft Excel
- .NET Framework 4.8
- Microsoft Visual Studio Tools for Office Runtime



## ダウンロード・インストール

最新版は以下からインストールできます。

-[自己署名証明書 をダウンロード](certificate/hiro-signature.cer)
-[setup.exe をダウンロード](setup.exe)

初めてインストールする場合は、先に自己署名証明書を登録してから `setup.exe` を実行してください。



## インストール

### 1. 証明書のインストール

本アドインは、公的な認証局から発行されたコード署名証明書ではなく、作者が作成した自己署名証明書をClickOnce署名に使用しています。

この証明書は本アドインの ClickOnce 署名に使用している自己署名証明書です。

インストールする場合は、この証明書をダウンロードし、以下の2か所に登録する必要があります。

- 信頼されたルート証明機関
- 信頼された発行元


証明書を信頼すると、この証明書によって署名されたプログラムをWindowsが信頼するようになるため、内容を理解したうえでインストールしてください。

【信頼されたルート証明機関へ登録】
1. `hiro-signature.cer` をダブルクリックして、「証明書のインストール」を押します。
2. 証明書のインポートウィザードで、「保存場所：ローカル コンピューター」を選びます。
3. 管理者権限の確認が出たら許可します。
4. 「証明書をすべて次のストアに配置する」を選択します。
5. 「参照」から「信頼されたルート証明機関」を選択します。
6. そのまま完了まで進めます。

【信頼された発行元へ登録】
1. `hiro-signature.cer` をダブルクリックして、「証明書のインストール」を押します。
2. 証明書のインポートウィザードで、「保存場所：ローカル コンピューター」を選びます。
3. 管理者権限の確認が出たら許可します。
4. 「証明書をすべて次のストアに配置する」を選択します。
5. 「参照」から「信頼された発行元」を選択します。
6. そのまま完了まで進めます。



### 2. アドインのインストール

`setup.exe` を実行してください。

インストール中に、.NET Framework 4.8 や　Microsoft Visual Studio Tools for Office Runtime　のインストールを求められた場合は、インストールしてください。



## 自動更新

本アドインはClickOnceを使用しています。

Excel起動時に更新を確認し、新しいバージョンが公開されている場合は更新されます。



## アンインストール

Windowsの「インストールされているアプリ」から削除できます。



## 注意事項

本ソフトウェアの使用前に、重要なExcelファイルについてはバックアップを作成してください。

本アドインは自己署名証明書を使用しています。
証明書をインストールする場合は、その意味を理解したうえで行ってください。
